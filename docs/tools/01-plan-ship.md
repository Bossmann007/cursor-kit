# Plan → ship

Disciplina. explorar → planejar → implementar → revisar. Código por último.

## No Cursor

- Plugin **superpowers** (brainstorm / plan / TDD / debug).
- Skill **`/poteto-mode`** para engenharia não trivial (playbooks + princípios).
- Fluxo curto do kit. [WORKFLOWS](../WORKFLOWS.md).

## Limite

Sem o plugin/skill certos, o agente volta ao “já codifica”. O playbook não substitui a disciplina da sessão.
