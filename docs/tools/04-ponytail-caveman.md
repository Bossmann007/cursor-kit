# Ponytail + Caveman

Duas regras globais em `~/.cursor/rules/`.

| Rule | Governa |
|------|---------|
| ponytail | O que construir (escada YAGNI, diff mínimo) |
| caveman | Como falar (menos enchimento; dados intactos) |

Independentes. Pode ligar uma intensidade (`ponytail lite`, `caveman full`, etc.) sem a outra.

## Limite

Não vivem no repo alvo. Se o global não tiver as rules, o `/setup-project` deve avisar no pré-check, não copiar silencioso para o projeto.
